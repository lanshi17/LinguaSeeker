# 波兰乳腺癌患者中BRCA1和BRCA2致病性突变的流行情况：来自下西里西亚地区遗传检测队列的发现

## 摘要

**背景**：BRCA1/2基因的致病性突变（PVs/LPVs）的流行率及其类型在不同人群中存在差异，因此需要针对特定地区进行数据分析，以识别反复出现的突变和非反复出现的突变，并评估现有诊断策略的有效性。目前发表的相关研究主要集中在北美、西欧或北欧地区。为填补这一研究空白，我们首次对中欧地区的BRCA基因检测结果进行了全面分析。

**方法**：我们对来自下西里西亚（波兰）的1,021名乳腺癌患者（治疗时间介于2024年3月至2025年4月之间）进行了下一代测序（NGS）检测。比较了携带BRCA1/2致病性突变的患者与未携带突变患者的临床和病理特征。

**结果**：在30名患者中（占样本总数的2.94%；95%置信区间：2.07%–4.16%）共检测到19种不同的致病性突变（其中11种位于BRCA1基因，8种位于BRCA2基因）。最常见的突变是BRCA1基因的c.5266dup突变（占所有突变的30%），其次是c.181T>G突变（占10%）。大多数突变（56.7%）为首次在该地区发现的独特突变；未检测到任何拷贝数变异。携带致病性突变的患者在诊断时的年龄显著更年轻（中位年龄为47岁，而非携带突变患者为66岁；p < 0.0001），并且表现出独特的肿瘤特征： triple-negative乳腺癌的发病率显著更高（43.3% vs 8.5%；OR = 8.24；p < 0.0001），雌激素受体（ER）和孕激素受体（PR）的表达水平较低，Ki-67蛋白的表达水平较高，肿瘤体积较大，诊断时肿瘤分期也更晚（所有这些差异均具有统计学意义，p < 0.05）。

**结论**：在本项未经过特殊选择的波兰地区队列中，BRCA1/2致病性突变的流行率低于以往的研究报告；其中非反复出现的突变占比较高。本研究的结果与国际研究结果一致。我们的发现表明，基于“创始突变”（founder mutation）的检测策略效果有限，建议在常规临床实践中采用基于下一代测序（NGS）的全面检测方法，以提高临床相关突变的检出率并指导治疗决策。

## 引言

在乳腺癌（BC）患者中，基因检测的应用日益普遍。这一现象既与乳腺癌的高发病率（普通人群的发病风险为12%）有关，也与携带致病性突变（PVs）或可能具有致病性的变异（LPVs）的个体能够获得有效预防性治疗有关[1]。此外，十年前卵巢癌领域引入了有效的PARP抑制剂疗法，随后这一疗法也被应用于乳腺癌、胰腺癌和前列腺癌，进一步推动了该领域基因检测数量的增加。这种更广泛的临床应用提高了对基因检测的需求，包括分析来自组织样本的肿瘤DNA（tDNA）或通过液体活检获得的循环肿瘤DNA（ctDNA）中的体细胞变异，以及从血液或拭子中提取的基因组DNA（gDNA）中的生殖系变异[2–5]。

乳腺癌的分子特征分析也得益于这样一个事实：导致乳腺癌、卵巢癌、前列腺癌和胰腺癌的驱动突变（PVs和LPVs）大多发生在几个特定基因上，这些基因包括BRCA1、BRCA2、PALB2、ATM、PTEN、RAD51C、RAD51D和TP53[5]。据估计，这些基因中的任何一个发生突变都可能导致5–10%的乳腺癌病例和约15–20%的卵巢癌病例。此外，在乳腺癌病例中，50%的临床显著变异属于BRCA1/2基因突变；而在卵巢癌病例中，这一比例高达80%[4, 6–8]。

大规模的荟萃分析表明，与遗传性乳腺癌和卵巢癌综合征（HBOCS）相关的致病性和可能具有致病性的基因变异的流行率因人群（地理位置、种族）而异，因此应在当地进行调查以识别任何特定的、反复出现的变异。拷贝数变异（CNVs，如外显子或整个基因的缺失/重复）以及非编码区域的变异也应被纳入考虑范围，因为它们可能占所有基因变异的5–10%[8]。

在一些人群中（包括中欧和东欧人群），观察到的BRCA1和BRCA2致病性变异中，BRCA1 c.5266dup p.(Gln1756fs)变异（根据Breast Cancer Information Core (BIC)的命名标准，该变异在阿什肯纳兹犹太人群中较为常见）尤为普遍。除了BRCA1 c.5266dup之外，在中欧和东欧（尤其是斯拉夫人群）中报告最常见的致病性变异还包括：c.181T > G (BIC: 300T > A) p.(Cys61Gly)、c.4035del (BIC: 4153delA) p.(Glu1346fs)、c.68_69del (BIC: 185delAG) p.(Glu23fs)等。这些常见BRCA1/2变异在所有BRCA1/2变异中的占比因人群而异[9–12]。需要强调的是，尽管在下一代测序（NGS）时代之前就已经开展了关于特定变异和LPVs频率的研究，但这些估计结果可能存在偏差，尤其是对于最常见的变异而言，其比例可能被高估了。目前，通过大规模并行测序整个BRCA1/2编码序列来检测单核苷酸变异（SNVs）和插入/缺失变异（indel variants），并结合拷贝数变异（CNVs）已成为研究这些基因的基本方法，从而能够较为准确地评估BRCA1/2相关癌症患者及普通人群中个体基因变异的频率和类型。

我们使用下一代测序（NGS）技术，对波兰下西里西亚地区1,351名乳腺癌患者的BRCA1/2致病性和可能具有致病性的变异进行了分析。据我们所知，这是中欧地区首次完成的全面BRCA1/2基因分析，因为之前的研究主要来自北美、西欧和北欧的队列。

## 材料与方法

本研究使用的是全外周血样本。遗传物质的提取方法及其质量评估过程已由Doraczynska-Kowalik等人[2]详细描述过。

本研究采用了Devyser BRCA试剂盒（Devyser AB，瑞典）来测序BRCA1和BRCA2基因的外显子及其外显子-内含子边界，并分析这些外显子的拷贝数。数据分析和致病性/可能致病性突变的确认方法同样由Doraczynska-Kowalik等人[2]提出。

对于那些NGS（下一代测序）检测未能检测到拷贝数变异（CNVs）的样本，我们按照制造商的协议，使用Salsa MLPA Probemix P002（针对BRCA1）和Salsa MLPA Probemix P045（针对BRCA2/CHEK2，MRC-Holland，阿姆斯特丹，荷兰）进行了MLPA检测。研究组中未发现任何拷贝数变异。突变的分类采用了美国医学遗传与基因组学学院（ACMG-AMP）制定的标准[14]。

本队列研究的报告遵循STROBE指南[15]的要求。

### 统计分析

BRCA1/2基因中致病性/可能致病性突变的检出率及其95%置信区间是通过Wilson评分法和Clopper–Pearson精确法计算得出的。那些NGS检测结果尚未确定的患者（NGS结果为“无数据”；n = 330）被排除在统计分析之外（实际用于分析的样本数为n = 1,021）。对于连续型变量（年龄、肿瘤大小、Ki-67、ER和PR表达水平），我们使用了Mann–Whitney U检验；对于分类型变量（分子亚型、HER2状态、疾病分期），则使用了Fisher精确检验或Pearson卡方检验，来比较携带致病性/可能致病性突变的患者（n = 30）与非携带者（n = 991）之间的临床和病理特征差异。各亚组内的数据正态性通过Shapiro–Wilk检验进行评估。Mann–Whitney U检验的效果量计算公式为r = 1 – 2U/(n1·n2)。所有检验均为双尾检验，显著性水平α = 0.05。数据分析使用的是Python 3（SciPy 1.x、pandas 2.x）软件。

## 研究结果

在1,021名乳腺癌患者中，共检测到19种不同的基因突变（Pathogenic Variants, PVs/LPVs）：其中11种与BRCA1基因相关，8种与BRCA2基因相关。这些突变的总体发生率为2.94%，95%置信区间为2.07%–4.16%（Wilson评分法）和1.99%–4.17%（Clopper–Pearson评分法）（见表2）。在下西里西亚地区，BRCA1基因中的c.5266dup突变最为常见，占所有BRCA1突变的42.86%（9/21），以及所有BRCA1/2突变的30%（9/30）。其次是BRCA1基因中的c.181T > G（C61G）突变，占10%（3/30）。另有1种非重复性突变（c.658_659del）出现在2名患者中；其他突变均为单独发生的。研究中未观察到拷贝数变异（Copy Number Variations, CNVs）。研究结果详见表3、表4和表5，以及图1（数据来源于cBio癌症基因组学门户网站，访问日期为2026年3月29日）[16]。

### 结果分析

BRCA1/2基因突变携带者诊断乳腺癌的年龄明显低于非携带者：携带者的中位诊断年龄为47岁（四分位数范围：40–60岁），而非携带者为66岁（四分位数范围：53–72岁），两者相差19岁。这一差异得到了非参数统计和参数统计分析的支持（Mann–Whitney U = 6568.0, p < 0.0001；t = −5.96, p < 0.0001），效应量较大（r = 0.56），表明携带者的癌症发病年龄显著提前（见表5）。

### 表5：BRCA1/2基因突变的分子亚型特征

- BRCA1/2突变携带者的肿瘤生物学特征与非携带者存在显著差异：
  - 激素受体表达水平较低：携带者的ER受体表达中位值为1%，PR受体表达中位值为0%，而非携带者分别为100%和70%（p < 0.0001）。
  - 增殖活性较高：携带者的Ki-67指数中位值为30%，而非携带者为20%（p < 0.001）。
  - 携带者的肿瘤在诊断时体积较大（中位数：27.5毫米，而非携带者为18.0毫米，p = 0.013），且更常处于晚期（IIIA–IV期：20.0%，而非携带者为约10.0%，p < 0.001）。
- 两组之间的HER2阳性率无显著差异（p = 0.754）。

综上所述，BRCA1/2基因突变与乳腺癌的发病机制和肿瘤生物学特性密切相关。

### 制约因素

本研究的一个主要限制在于队列的构成。共有330名患者（占24.43%）因缺乏知情同意而被排除在外；另有少数患者因之前已经接受了广泛的BRCA1/2基因组测序（NGS）检测而未被重新检测。虽然移除了这些可能携带突变的患者可能会略微低估突变的实际发生率，但考虑到BRCA1/2基因变异在人群中的高发率，这种影响预计是有限的。在解释研究结果并将其与其他已定义的队列进行比较时，这一点需要予以考虑。同时，这也反映了波兰现实世界的临床实践：通常情况下，之前接受过检测的患者不会被重新检测。

波兰乳腺癌患者亚群体中BRCA1和BRCA2基因的携带率可能因研究所在的地理区域和种族群体的不同而有所差异。下西里西亚地区的人口主要由二战期间从现今乌克兰西部（原属加利西亚、沃尔希尼亚和波莱西亚地区）返回的移民后裔组成，此外还有在战后时期从波兰其他地区迁入的人口。因此，该地区BRCA基因变异的分布可能与其他波兰或欧洲地区存在差异。

尽管我们的研究结果表明，检测到的BRCA1/2基因变异中大部分是非重复性的（即非反复出现的突变），这暗示了基于创始人突变（founder mutations）的检测策略可能存在局限性，但本研究并非旨在直接比较针对特定突变的检测方法与基于下一代测序（NGS）的全面检测方法的诊断效果。

此外，研究样本量相对较小，这限制了我们全面了解所有可能存在的基因变异的能力。

## 结论

高通量测序技术的广泛应用使得人们能够检测完整的基因编码序列，从而在一次检测中分析所有潜在的基因变异。鉴于下一代测序（NGS）技术所带来的便利，如果仅对癌症患者进行最常见的几种基因变异的检测，可能会对患者及其亲属造成不利影响——因为这会限制他们的治疗或预防选择。值得注意的是，包括美国国家综合癌症网络（National Comprehensive Cancer Network）在内的国际指南越来越多地推荐对乳腺癌患者进行多基因检测，并放宽了基因检测的适用条件。这一趋势反映了人们对基因异质性的日益重视，以及NGS技术成本的不断下降。根据现有数据，决策者应考虑在各国推行普遍性的基因检测计划，这不仅有利于公民的健康和福祉，还能通过预防性手术和早期肿瘤检测来降低未来的癌症治疗成本；此外，生活方式的改变、化学预防措施以及遵循个性化的监测方案等额外风险降低策略也同样具有重要意义。
