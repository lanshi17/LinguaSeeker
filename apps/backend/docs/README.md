# docs/ 目录导航（代码对齐版）

本目录用于维护产品契约、工程结构与执行计划。以当前仓库文件为准。  
当前项目名称统一为：`ACMG-Lingua`。

## 1. 冻结规范（优先阅读）

1. `PRD.md`
2. `BACKEND_STRUCTURE.md`
3. `APP_FLOW.md`
4. `TECH_STACK.md`
5. `FRONTEND_GUIDELINES.md`
6. `IMPLEMENTATION_PLAN.md`
7. `CONSTANTS.md`

## 2. 变更与评估

- `CHANGE_CONTROL.md`
- `EVALUATION_FRAMEWORK.md`
- `PS3_BS3_VALIDATION_REPORT.md`

## 3. 计划与归档

- `plans/`：当前实施计划（先读 `plans/README.md`）
- `archive/`：历史计划与过期图稿，不作为默认执行依据

## 4. 使用约定

- 新需求先更新/对齐冻结规范，再写执行计划。
- 涉及状态、错误码、重试、保留策略变更时，必须同步更新冻结文档与变更记录。
- `docs/archive/` 中内容仅用于追溯，不直接驱动当前实现。
