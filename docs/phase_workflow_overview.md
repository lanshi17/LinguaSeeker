# ACMG Lingua 工作流说明

## 项目概述

ACMG Lingua 是一个面向医学遗传学文献的自动化证据提取平台。系统将多语言医学文献作为输入，通过四个阶段的流水线处理，输出符合 ACMG 标准的结构化变异致病性证据，供临床专家审查使用。

---

## 四阶段工作流

### Phase 1：文献获取与数字化

**目标**：从多种来源获取医学文献 PDF，并将其转换为结构化的可处理文本。

- **输入**：用户提供的关键词、DOI、PMID，或直接上传的 PDF 文件
- **处理过程**：
  1. 多源文献检索（Crossref、PubMed、OpenAlex 等 15+ 数据源）
  2. PDF 全文下载（含多级回退策略）
  3. 文档解析（MinerU 引擎提取文本、表格、图片、公式）
- **输出**：按页组织的 Markdown 文本、文档元数据、提取的图片

### Phase 2：跨语言处理与证据提取

**目标**：消除语言障碍，从文献中精准提取与变异致病性相关的证据。

- **输入**：Phase 1 输出的结构化文档
- **处理过程**：
  1. 文本格式化与语言检测
  2. 非英文文献自动翻译为英文（保持医学术语一致性）
  3. 原文与译文双轨并行提取证据（基于 ACMG 证据字段目录）
  4. 证据源定位（将每条证据精确回溯到文档中的原始位置）
  5. 证据分组（按基因-变异对聚合）与证据链构建
  6. 质量审查（源有效性、缺失项、矛盾检测）
- **输出**：双轨证据数据（原文 + 译文）、证据链、质量报告

### Phase 3：实体标准化与知识对齐

**目标**：将提取的实体名称统一到国际标准命名，并与权威数据库交叉比对。

- **输入**：Phase 2 输出的双语证据数据
- **处理过程**：
  1. 从双轨证据中提取候选实体（基因、疾病、表型、变异）
  2. 确定性精确匹配：基因→HGNC、疾病→OMIM、表型→HPO、变异→ClinVar
  3. 匹配结果分类：唯一匹配（标准化）/ 多候选（待消歧）/ 无匹配（未映射）
  4. 持久化：标准化实体、证据-实体绑定、规范证据记录
- **输出**：标准化实体绑定、规范证据记录、匹配状态报告

### Phase 4：双语可视化与专家审查

**目标**：为临床专家提供直观的审查界面，并将审查反馈用于系统持续优化。

- **输入**：Phase 3 输出的标准化证据
- **处理过程**：
  1. 中英文对照展示（原文与译文并排，证据源高亮定位）
  2. 专家在线审查（确认、修正、补充证据项）
  3. 生成 ACMG 标准格式的证据报告（JSON / PDF）
  4. 审查反馈回流，优化模型提取能力
- **输出**：最终 ACMG 证据报告、专家审查记录

---

## 端到端数据流

```
用户输入（关键词/DOI/PDF）
    │
    ▼
[Phase 1] 文献获取 → 结构化文档
    │
    ▼
[Phase 2] 跨语言翻译 + 双轨证据提取 → 双语证据 + 质量报告
    │
    ▼
[Phase 3] 实体标准化 + 数据库比对 → 标准化证据
    │
    ▼
[Phase 4] 可视化展示 + 专家审查 → 最终 ACMG 报告
```
