## Goal
落地 `v1.0` 基线：多源文献获取 + 6 节点流程 + 三个独立微服务 + 完整 JSON 溯源链。

## Scope
1. Acquisition: API + crawler 多源适配与调度。
2. Workflow: 6 节点（获取/解析/翻译/提取/ACMG分类/专家裁决）。
3. Services: `pdf-parser-service`, `translation-service`, `evidence-extraction-service`。
4. Traceability: 节点输入输出、来源链路、证据定位可追溯。

## Milestones
### M1: Acquisition & Orchestration
1. 接入并统一 API/crawler 适配层。
2. 实现调度智能体源选择与源级重试策略。
3. 建立来源追踪字段（`source_trace`）。

### M2: 6-Node Execution
1. 扩展流程到 6 节点并保证状态回传。
2. ACMG 分类与专家裁决拆分输出。
3. 保持 `queued/running/partial_failed/failed/success` 请求状态兼容。

### M3: Service Boundary Hardening
1. 解析微服务输出 `md/jpg` 到 MinIO。
2. 翻译微服务输出英文 `md` + BGE-M3 入 Qdrant。
3. 提取微服务集成 scispaCy + LlamaIndex + reranker。

### M4: Contract & Verification
1. 输出 JSON 溯源链字段稳定。
2. 100 文献验收集跑通，成功率与时长达标。
3. 补齐 release note 与 backward impact（已完成）。

## Verification Checklist
