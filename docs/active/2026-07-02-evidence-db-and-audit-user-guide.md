## 第一部分：Evidence DB — 证据数据库浏览

**路径**: `/evidence-db`

Evidence DB 是以变异（Variant）为中心的证据浏览系统。系统将来自多篇文献的证据自动聚合到变异维度，支持从总览到详情到原始文献的三级浏览。

### 1.1 变异索引视图 (L1)

打开 `/evidence-db` 后，首先看到的是所有变异的聚合列表。

#### 数据面板

页面顶部显示四个关键指标：

| 指标 | 含义 |
|------|------|
| **Unique Variants** | 数据库中的独立变异总数（按 Gene + Variant + Disease 聚合） |
| **Evidence Groups** | 证据组总数（每组 = 一篇文献提取的证据集） |
| **Literature Sources** | 文献来源总数 |
| **Avg Confidence** | 所有证据的平均提取置信度 |

#### 列表列说明

| 列 | 含义 | 说明 |
|----|------|------|
| **颜色条** | 致病性指示 | 行左侧 4px 色条，颜色对应致病性分类（红=致病，橙=可能致病，灰=VUS，青=可能良性，绿=良性） |
| **Gene / Variant** | 基因与变异 | 上方为基因符号（粗体），下方为 HGVS 变异命名 |
| **Disease** | 疾病 | 关联疾病名称 |
| **Class.** | 致病性分类 | ACMG 五级分类徽章（P / LP / VUS / LB / B） |
| **Evidence** | 证据覆盖 | 字母色块表示已覆盖的 ACMG 证据类别（A–K），悬停可查看详细标签 |
| **Refs** | 文献引用数 | 支持该变异的独立文献数量 |
| **Conf.** | 置信度 | 证据提取的平均置信度百分比，附色条指示（绿 ≥70%，橙 ≥40%，红 <40%） |

可选列（通过列表上方的切换按钮控制显示）：

| 可选列 | 含义 |
|--------|------|
| **Categories** | 证据类别分布条（彩色比例条，按 A–K 类别着色） |
| **Review Progress** | 审阅进度（已审阅/总字段数） |
| **Updated** | 最近数据更新时间 |

#### 筛选与搜索

**搜索栏**（第一行）：

- **Gene / Variant 搜索**：输入基因名或变异名，支持自动补全。例如输入 `MECP2` 或 `c.473C>T`
- **Disease 筛选**：按疾病名筛选，支持自动补全
- **Review Status 筛选**：按审阅状态过滤（待审核 / 已批准 / 已修正 / 已驳回）

**分类与排序栏**（第二行）：

- **Classification 过滤**：点击致病性分类药丸按钮筛选特定分类
- **Sort 排序**：按基因、变异、疾病、分类、证据数、文献数、置信度、更新时间排序
- 排序方向可通过箭头按钮切换（升序/降序）
- 点击 **Clear** 清除所有筛选条件

#### 证据类别字母含义

行中 Evidence 列显示的字母色块代表该变异在各 ACMG 证据领域的覆盖情况：

| 字母 | 类别 | 说明 |
|------|------|------|
| **A** | Variant Information | 变异基本信息（基因、转录本、HGVS 命名、变异类型） |
| **B** | Case/Phenotype | 病例与表型（疾病诊断、HPO 术语、发病年龄） |
| **C** | Segregation/Family | 家系与分离（新发/遗传、父母基因型、LOD 值） |
| **D** | Population/Frequency | 人群频率（gnomAD 等数据库频率、纯合子计数） |
| **E** | Computational/Prediction | 计算预测（SIFT、PolyPhen、剪接预测、保守性） |
| **F** | Functional Evidence | 功能实验（实验类型、结果、对照、OddsPath） |
| **G** | Case-Control | 病例对照研究（OR 值、P 值、研究设计） |
| **H** | Contradiction/Exclusion | 矛盾/排除证据（误诊、替代病因、不分离） |
| **I** | Gene Function/Experimental | 基因功能与实验（动物模型、细胞模型、回复实验） |
| **J** | Authority/Time Validity | 权威来源（ClinVar、专家面板、已知致病参考） |
| **K** | Gene-Disease Validity | 基因-疾病有效性（GDV 评分、ClinGen 分类） |

### 1.2 变异详情视图 (L2)

在 L1 列表中点击任一变异行，进入该变异的详情页面。

#### Hero 区域

页面顶部展示变异的核心信息：

- **基因符号** + **致病性分类徽章**
- **HGVS 变异命名**
- **关联疾病**
- **完整分类描述**
- **冲突标记**（如存在跨文献矛盾）

右侧统计面板：

| 指标 | 含义 |
|------|------|
| 置信度环 | 圆形进度指示器，显示平均置信度 |
| Literature | 文献引用数 |
| Evidence Fields | 提取的证据字段总数 |
| Coverage | 已覆盖的证据类别数 / 总类别数 |
| Reviewed | 已审阅字段数 / 总字段数 |

#### 证据分类面板（左侧）

证据按 A–K 类别分组显示，每个类别面板包含：

- **类别标题**：彩色圆点 + 类别字母 + 名称 + 字段数
- **证据条目卡片**：每张卡片显示
  - 字段名（如 `Gene symbol`）
  - 提取的值（2 行截断）
  - 类别标签
  - 字段 ID（如 `A.gene_symbol`）
  - 置信度百分比（颜色编码：绿 ≥70%，橙 ≥40%，红 <40%）
  - 数据轨道标记（original / translated / reconciled）

#### 文献引用列表（右侧）

每篇文献卡片显示：

- 文献标题（可点击，跳转至 L3 双语视图）
- PMID 和 DOI
- 提取字段数和置信度
- 已审阅计数
- 可用标记（全文 / 已翻译）
- 冲突标记
- 覆盖的类别字母
- 双语预览（最多 3 条原文/翻译对照）

### 1.3 双语证据对比视图 (L3)

在 L2 文献列表中点击某篇文献，进入双语对比视图。

#### 布局

- **左侧面板**：原文文档（原始语言）
- **右侧面板**：翻译文档（自动翻译）
- **侧边栏**：文献元数据、控制面板

#### 功能

- **同步滚动**：左右面板按比例同步滚动，便于逐段对照
- **证据高亮**：文档中的证据段落按类别（A–K）着色高亮
- **结构化块**：文档按章节结构化渲染（标题、段落、表格）
- **侧边栏控制**：
  - 切换原文/翻译面板的显示
  - 查看证据提取摘要
  - 跳转至其他文献

### 1.4 ACMG/ClinGen 证据分类系统

本系统按照 ACMG/ClinGen 指南定义的证据分类体系提取和组织证据。每个证据字段归属一个类别，对应 ACMG 评估的不同维度：

**致病变异证据强度等级**：

| 强度 | Pathogenic 方向 | Benign 方向 |
|------|----------------|-------------|
| Very Strong | PVS1 | — |
| Strong | PS1–PS4 | BS1–BS4 |
| Moderate | PM1–PM6 | BM1–BM5 |
| Supporting | PP1–PP5 | BP1–BP7 |

**系统覆盖 166 个证据字段**，分布在 11 个类别中（A–K），完整字段目录可在 `frontend/src/lib/constants/evidenceFields.ts` 中查看。

### 1.5 致病性分类

系统自动计算或从文献中提取的五级致病性分类：

| 分类 | 缩写 | 颜色 | 含义 |
|------|------|------|------|
| Pathogenic | P | 红色 | 致病性变异 |
| Likely Pathogenic | LP | 橙色 | 可能致病 |
| VUS | VUS | 灰色 | 意义不确定 |
| Likely Benign | LB | 青色 | 可能良性 |
| Benign | B | 绿色 | 良性变异 |

### 1.6 数据导出

L1 列表支持批量导出：

1. 使用列表左侧的复选框选中要导出的变异
2. 或点击表头的全选复选框选中当前页所有变异
3. 在弹出的批量操作栏中选择导出格式：
   - **CSV**：含 BOM 的 UTF-8 编码，Excel 可直接打开
   - **JSON**：结构化 JSON，包含完整的变异元数据

导出字段包括：gene、variant、disease、classification、evidence_groups、literature_refs、avg_confidence、review_status、created_at、title、pmid、doi。

## 第二部分：审核与标注 — 证据审阅操作

**路径**: `/audit`

审核模块用于对系统自动提取的证据进行人工审核、修正和质量标注。所有审阅操作都会记录到审计日志中，确保可追溯性。

### 2.1 审核事件日志

审核页面默认显示所有审阅事件的日志列表。

#### 指标面板

页面顶部显示审阅统计：

| 指标 | 含义 |
|------|------|
| **Total Events** | 审阅事件总数 |
| **Approved** | 批准操作数 |
| **Corrected** | 修正操作数 |
| **Rejected** | 驳回操作数 |

#### 事件筛选

- **状态筛选**：按状态过滤（全部 / 待审核 / 已批准 / 已修正 / 已驳回）
- **文本搜索**：搜索证据 ID、字段名、变更原因

#### 事件列表

每条事件显示：

- 证据 ID（UUID，可复制）
- 字段名（如 `gene_symbol`）
- 审阅人
- 状态变更（如 `provisional → approved`）
- 变更原因
- 操作时间

点击任一事件可查看字段级别的变更详情（旧值 → 新值的差异对比）。

事件列表每 10 秒自动刷新。

### 2.2 证据审阅抽屉

在审核页面点击 **Review Evidence** 按钮，打开证据审阅抽屉。

#### 默认行为

抽屉打开后自动加载所有证据条目列表。每条显示：

- **Gene / Variant**：基因名 + 变异名
- **Review Status 徽章**：当前审阅状态
- **Disease / Classification 标签**
- **PMID 标签**（如有）
- **统计信息**：字段数 + 平均置信度

#### 筛选证据

在搜索栏中使用以下字段缩小列表范围（所有字段可选）：

- **Gene**：按基因名筛选
- **Variant**：按变异名筛选
- **Disease**：按疾病名筛选

输入后点击 **筛选** 按钮应用过滤条件。清空所有字段后点击筛选可恢复完整列表。

#### 选择证据条目

在列表中点击任一证据条目，进入审阅面板。

### 2.3 审阅操作流程

#### Step 1: 查看证据字段

审阅面板顶部显示变异的摘要信息（基因、变异、分类、证据组数）。

下方列出该证据组的所有字段，每个字段卡片显示：

- **字段 ID**（如 `A.gene_symbol`）和**类别标签**
- **当前值**（系统提取的值）
- **修正输入框**（如需修改，在此输入正确的值）
- **变更指示器**（输入修正值后，卡片边框变为琥珀色）

> 并非所有字段都可以修正值——只有映射到后端可更新字段的条目才显示可编辑输入框。

#### Step 2: 设置审阅状态

在面板底部设置目标审阅状态：

| 状态 | 含义 | 使用场景 |
|------|------|----------|
| **Approved** | 批准 | 所有字段值正确，无需修改 |
| **Corrected** | 修正 | 发现错误并已修正部分字段值 |
| **Rejected** | 驳回 | 数据质量不可用，需要重新提取 |

#### Step 3: 填写变更原因

在 Reason 输入框中简要说明审阅理由，例如：

- "所有字段与原文一致，批准通过"
- "修正了基因符号拼写错误"
- "文献内容与该变异无关，驳回"

变更原因会记录到审计日志中，供后续追溯。

#### Step 4: 提交审阅

点击 **Submit Review** 按钮提交。系统将：

1. 对所有修正的字段值发送 PATCH 请求
2. 更新审阅状态
3. 记录审阅事件到审计日志
4. 显示成功消息（包含审阅的条目数和字段变更数）
5. 自动刷新审计事件列表
6. 关闭抽屉

#### 审阅注意事项

- 一次审阅操作可以同时修正多个字段并更改状态
- 如果仅更改状态而不修正任何字段值，同样会记录审阅事件
- 同一证据可以被多次审阅，每次审阅都会追加审计记录
- 审阅操作不可撤销，但可以通过后续审阅覆盖状态和字段值

## 附录：常见问题

### Q: 置信度数值代表什么？

置信度反映系统从文献中提取证据时的确定性程度（0–100%）。它基于 NLP 模型的提取置信度计算，受文本清晰度、语言复杂度和提取字段完整度影响。高置信度（≥70%）通常意味着提取值可靠，低置信度（<40%）建议优先人工审核。

### Q: 证据类别分布条中不同颜色代表什么？

分布条中的每段颜色对应一个 ACMG 证据类别（A–K），宽度表示该类别中字段数的比例。完整的 11 个类别覆盖从变异基本信息到基因-疾病有效性评估的所有维度。

### Q: 为什么某些变异没有致病性分类？

致病性分类需要足够的证据支持。如果文献中未明确给出分类，或提取的证据不足以自动推断，系统会标记为 VUS（意义不确定）。

### Q: 双语视图中的 "reconciled" 轨道是什么？

系统对原始语言和翻译语言的证据进行交叉验证后，生成融合（reconciled）轨道作为最终提取结果。融合轨道综合了两个语言版本的信息，是质量最高的证据来源。

### Q: 如何查看某篇文献提取了哪些证据？

在 L2 变异详情页右侧的文献列表中，点击目标文献卡片，即可进入 L3 双语对比视图。左侧面板显示原文（证据段落高亮），右侧显示翻译，侧边栏展示结构化提取结果。
