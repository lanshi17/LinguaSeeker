# 前端开发快速指南

## 开发前必读
在进行任何前端开发前，请务必阅读并理解[前端开发宪法原则](FRONTEND_CONSTITUTION.md)，违反宪法原则的代码将不会被接受。

## 核心原则摘要
1. **技术栈**：仅使用Vite + React + TypeScript
2. **类型安全**：所有数据必须有明确的TypeScript类型定义
3. **安全性**：使用DOMPurify清理HTML内容，不硬编码敏感信息
4. **用户体验**：确保响应式设计和无障碍访问
5. **数据展示**：按规范展示证据字段，空值显示"—"

## 禁止行为
- 不得修改后端API接口定义
- 不得绕过类型检查或滥用`any`类型
- 不得直接操作DOM元素
- 不得引入未经审查的第三方库
- 不得破坏现有功能

## 代码审查清单
在提交代码前，请确认：
- [ ] 遵循命名约定（kebab-case, PascalCase, camelCase）
- [ ] 包含适当的JSDoc注释
- [ ] 所有TypeScript类型定义完整
- [ ] 代码长度符合限制（函数≤50行，组件≤200行）
- [ ] 包含必要的测试用例
- [ ] 通过ESLint和TypeScript检查

## 违规后果
违反宪法原则的代码将被拒绝合并，开发者需要重新修改直至符合规定。
