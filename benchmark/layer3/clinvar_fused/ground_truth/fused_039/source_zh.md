# 格兰兹曼血小板无力症及其他遗传性血小板功能障碍的基因确认与新型变异体鉴定：韩国儿科血液肿瘤学组（KPHOG）的研究

## 摘要

由于韩国部分医疗机构缺乏必要的检测技术（如光透射聚集试验和流式细胞术），遗传性血小板功能障碍（IPFDs）的诊断一直面临挑战。本研究由韩国儿科血液肿瘤学组于2017年3月至2020年12月期间开展，旨在利用下一代测序（NGS）技术识别韩国患者中导致IPFDs的基因变异体。研究首先对目标外显子区域进行测序，随后进行全基因组测序以确诊IPFDs。在纳入研究的11名疑似IPFDs患者中，10名患者及其2名家庭成员被诊断为格兰兹曼血小板无力症（Glanzmann thrombasthenia, GT）。最常见的变异体为ITGB3基因的c.1913+5G>T突变，其次是ITGB2B基因的c.2333A>C（p.Gln778Pro）突变。此外，还发现了已知的GT相关变异体，如ITGB3基因的c.917A>C（p.His306Pro）、c.2975del（p.Glu992Glyfs*）、c.257T>C（p.Leu86Pro）以及ITGA2B基因的c.1750C>T（p.Arg584*）突变。同时，本研究还发现了4种新的GT相关变异体：ITGB3基因的c.1451G>T（p.Gly484Val）、c.1595G>T（p.Cys532Phe），以及ITGA2B基因的c.1184G>T（p.Gly395Val）和c.2390del（p.Gly797Valfs*29）。最后一名患者被诊断为血小板型出血性疾病18型，并携带两种新的RASGRP2基因变异体（c.1479dup（p.Arg494Alafs*54）和c.813+1G>A）。本研究证明了NGS技术在准确诊断及鉴别不同类型的IPFDs方面的有效性。

## 1. 引言

遗传性血小板功能障碍（IPFDs）是一组具有异质性的疾病，其发病机制涉及血小板功能的先天性缺陷，包括血小板的黏附、活化、信号传导、颗粒分泌、聚集及促凝活性等方面的异常[1, 2]。格兰兹曼血小板无力症（Glanzmann thrombasthenia, GT，OMIM #273800）是最典型的IPFD类型，患者终生伴有出血症状[3]。该病属于常染色体隐性遗传病，其根本原因是ITGA2B或ITGB3基因突变导致GP-IIb/GP-IIIa糖蛋白复合物的结构或功能异常，从而引发血小板聚集功能障碍[3]。此外，还存在其他几种具有类似临床表现的IPFD类型，例如Bernard–Soulier综合征、获得性GT、白细胞黏附缺陷III型以及与RASGRP2蛋白相关的血小板功能障碍[4]。

根据国际血栓与止血学会（International Society of Thrombosis and Haemostasis）的建议，光透射聚集试验（LTA）和流式细胞术（FC）是IPFDs的常规筛查方法[5]。然而，由于韩国国家医疗保险制度的限制，仅有少数医院能够开展这些检测。因此，在韩国难以准确诊断和识别各类IPFD病例，这些疾病的实际发病率及其遗传异常的分布情况仍不清楚。迄今为止，韩国仅报道过少数经过基因学确认的GT病例[2, 6]。本研究旨在利用下一代测序（NGS）技术对韩国患者的IPFDs进行基因确认及鉴别诊断。

## 2. 材料与方法

### 2.1. 研究对象与数据收集

这项多中心观察性、描述性研究由韩国儿科血液学与肿瘤学组（KPHOG）的良性血液学委员会于2017年3月至2020年12月期间开展。实验方案获得了庆明大学东山医院伦理委员会的批准（批准编号：2017-03-008），研究过程严格遵守《赫尔辛基宣言》的相关规定。在采集血液样本之前，所有参与者均签署了知情同意书。

本研究主要关注非综合征性血小板功能障碍（IPFD）患者，纳入标准如下：（1）血小板计数在正常范围内；（2）存在原发性止血问题，如瘀点、易瘀伤、频繁或严重的鼻出血、黏膜出血（包括牙龈出血或月经过多），或在接种疫苗、接受手术或分娩后仍持续出血；（3）实验室检测结果显示出血时间延长、血小板功能分析仪（PFA ® -100，Dade-Behring，德国马尔堡）的止血时间延长，或通过LTA检测发现血小板功能异常。排除标准包括：（1）患有骨髓衰竭、先天性异常、白化病、免疫缺陷或其他与综合征性遗传性血小板疾病相关的患者；（2）被诊断为冯·维勒布兰德病（von Willebrand disease）的患者。

### 2.2. 新一代测序（NGS）

为了识别与IPFD及凝血缺陷相关基因的致病性变异，首先进行了靶向外显子测序（Targeted Exome Sequencing, TES），随后进行全基因组测序（Whole Genome Sequencing, WGS）。在TES过程中，从EDTA抗凝处理过的全血中提取基因组DNA，并使用TruSight One（Illumina，美国加利福尼亚州圣地亚哥）和Custom panel（Celemics，韩国首尔）试剂盒制备测序文库。测序工作在Illumina NextSeq500平台（Illumina，美国加利福尼亚州圣地亚哥）上进行。序列比对及变异检测遵循GATK最佳实践指南进行。Fastq序列数据的修剪使用Trimmomatic工具完成；比对工作采用BWA-MEM（版本0.7.12）软件完成；重复序列的识别使用Picard（版本1.96，访问日期：2014年8月14日）工具完成；局部比对、碱基质量校正及变异检测通过Genome Analysis Toolkit（GATK，版本3.5）完成；注释工作则使用VEP88（Variant Effect Predictor）和dbNSFP v3.3工具完成。

在WGS过程中，同样从EDTA抗凝处理过的全血中提取基因组DNA，并使用BGI-T7平台进行双端测序。测序文库的构建及测序工作采用DNBSEQ-T7（MGI Tech Co., Ltd., 中国深圳）提供的100 bp双端读取技术完成。序列数据经过atropos（版本1.1.28）工具处理后，与公共人类基因组参考序列GRCh37/UCSC hg19进行比对；比对工作使用BWA-MEM（版本0.7.17）完成；重复序列的识别使用biobambam2工具完成；碱基质量校正及变异检测通过Genome Analysis Toolkit的HaplotypeCaller（版本4.1.8）完成；注释工作使用VEP101（Variant Effect Predictor）和dbNSFP v4.1工具完成。TES与WGS的测序质量指标详见表1。

所有检测到的变异均通过以下数据库进行注释：1000 Genomes Project [1000g]、Exome Variant Server、Exome Aggregation Consortium [ExAC]、Genome Aggregation Database [gnomAD]、Korean Reference Genome Database [KRGDB]以及OMIM疾病数据库。对于错义突变，采用SIFT、PolyPhen-2和MutationTaster工具进行计算机模拟分析。对于文献中尚未报道其临床意义的候选变异，其分类依据为美国医学遗传学与基因组学学院（ACMG）和分子病理学协会（AMP）2015年发布的序列变异解读指南[7]。

### 2.3. 主要研究基因

本研究关注的主要基因包括与IPFD及具有类似原发性止血问题的疾病相关的基因，例如：GT（ITGA2B、ITGB3）、Bernard–Soulier综合征（GP1BA、GP1BB、GP9）、腺苷二磷酸受体P2Y12缺陷（P2RY12）、血栓烷A2受体缺陷（TBXA2R）、血栓烷合成酶缺乏症（TBXAS1）、灰色血小板综合征（NBEAL2）、Paris–Trusseau/Jacobsen综合征（FLI1）、Chediak-Higashi综合征（LYST）、Hermansky–Pudlak综合征（HPS1、AP3B1、HPS3、HPS4、HPS5、HPS6、DTNBP1、BLOC1S3、BLOC1S6）、Scott综合征（ANO6）、魁北克血小板障碍（PLAU）以及其他类型的血小板出血性疾病（P2RY12、TBXA2R、PTGS1、GFI1B、EPHB2、ACTN1、RASGRP2、GP6）等。

## 3. 研究结果

在研究期间，我们收集了11名无亲属关系的韩国患者（男女比例为7:4）及其家庭成员的 peripheral blood 样本，这些患者疑似患有遗传性血小板功能障碍（IPFDs）。同时，我们也记录了他们的出血症状和实验室检测数据。通过下一代测序（NGS）技术，其中10例患者的基因型被确认为 GT（Genetic Thrombocytopathy），另有1例患者被诊断为血小板型出血性疾病 18（BDPLT18）。IPFD 患者的基线临床信息详见表 2，实验室检测结果及发现的基因变异信息汇总在表 3 中。大多数 IPFD 患者是在婴儿期出现症状的，常见的症状包括容易瘀伤、牙龈出血、出生后全身出现瘀点以及持续性鼻出血。

在11名韩国 IPFD 患者中，有10名患者及其2名家庭成员被确诊为 GT。ITGB3 基因中的 c.1913+5G>T 变异最为常见（共20个变异中占9例，占比45%）：其中3名患者为纯合子，另外3名为杂合子。ITGB2B 基因中的 c.2333A>C (p.Gln778Pro) 变异是第二常见的变异（占3例，占比15%），同样表现为杂合子。此外，还发现了其他已知的 GT 相关变异，如 ITGB3 基因中的 c.917A>C (p.His306Pro)、ITGA2B 基因中的 c.2975del (p.Glu992Glyfs*)、ITGA2B 基因中的 c.257T>C (p.Leu86Pro) 以及 ITGA2B 基因中的 c.1750C>T (p.Arg584*)。在4名无亲属关系的韩国 GT 患者中还发现了4个新的基因变异：ITGB3 基因中的 c.1451G>T (p.Gly484Val) 和 c.1595G>T (p.Cys532Phe)，以及 ITGA2B 基因中的 c.1184G>T (p.Gly395Val) 和 c.2390del (p.Gly797Valfs*29)。其中1名患者被诊断为 BDPLT18（OMIM #615888），并携带两种 RASGRP2 基因的新变异，即 c.1479dup (p.Arg494Alafs*54) 和 c.813+1G>A。

这4个新的 GT 基因变异详见表 4。在家族 1 中发现的 NM_000212.2 (ITGB3) 基因中的 c.1451G>T (p.Gly484Val) 变异在人群数据库中未被记录，且通过计算机模拟分析被预测为致病性变异。该变异也出现在患者的妹妹身上，她表现出与 GT 相同的出血症状。进一步通过 Sanger 测序确认，该变异与已知致病性变异 c.1913+5G>T (ITGB3) 共存。根据 2015 年 ACMG/AMP 分类标准 [7]，c.1451G>T (ITGB3) 被判定为可能具有致病性。患者 ID 1 和其妹妹均有明显的出血症状，如严重鼻出血、容易瘀伤和牙龈出血；两人因持续性鼻出血频繁就诊急诊室，入院时均出现严重贫血，需要输注红细胞。此外，两人全身都存在瘀点和瘀伤，他们的日托老师怀疑他们可能遭受了虐待。患者 ID 1 在每次看牙医时都会出现牙龈出血，因此我们在牙科手术前为其进行了预防性血小板输注。

在家族 8 中发现的 NM_000419.4 (ITGA2B) 基因中的 c.1184G>T (p.Gly395Val) 变异同样在人群数据库中未被记录，且通过计算机模拟分析被预测为致病性变异。该变异与已知致病性变异 c.1750C>T [p.Arg584*] (ITGA2B) 共存，这一结果通过 Sanger 测序得到了验证。根据 2015 年 ACMG/AMP 分类标准，c.1184G>T (ITGA2B) 被判定为可能具有致病性。患者 ID 8 参与本研究是因为她在出生后全身出现瘀点，并在出牙时伴有牙龈出血；她的伤口愈合缓慢，手指受伤时也会持续出血。由于全身经常出现瘀点和瘀伤，她在接种疫苗时改用了皮下注射方式作为出血预防措施。

NM_000419.4 (ITGA2B) 基因中的 c.2390del (p.Gly797Valfs*29) 变异也未在人群数据库中记录。该变异与家族 9 中的已知致病性变异 c.2333A>C [p.Gln778Pro] 共存，因此根据 2015 年 ACMG/AMP 分类标准被判定为致病性变异（该变异属于导致基因移码的“null”变异类型）。患者 ID 9 参与本研究是因为她有明显的出血症状：刷牙后牙龈容易出血，容易瘀伤，排便后还会出现肛门出血。

最后一个新的 GT 基因变异 NM_000212.2 (ITGB3) 中的 c.1595G>T (p.Cys532Phe) 在家族 10 中被发现，且在对照组人群中未出现。此前已有研究报道过在该位置发生其他氨基酸替换（如 p.Cys532Tyr [8] 和 p.Cys532Arg [9]）的 GT 病例。通过计算机模拟分析，c.1595G>T (ITGB3) 变异被预测为致病性变异，并与已知致病性变异 c.1913+5G>T (ITGB3) 共存，这一结果通过 Sanger 测序得到了验证。根据 2015 年 ACMG/AMP 分类标准，该变异也被判定为可能具有致病性。患者 ID 10 参与本研究是因为她出现了与上消化道出血相关的呕血症状。

## 5. 结论

本研究表明，通过下一代测序（NGS）技术可以实现遗传性血小板功能障碍（IPFDs）的鉴别诊断。因此，将NGS技术应用于多种类型的IPFDs有助于实现这些疾病的准确诊断与鉴别。

总之，我们证实了利用NGS技术能够对遗传性血小板功能障碍（IPFDs）进行鉴别诊断。这意味着将NGS技术应用于不同类型的IPFDs对于实现这些疾病的精准诊断与鉴别具有重要意义。
