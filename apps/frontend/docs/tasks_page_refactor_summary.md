### ✨ P1: 交互体验升级

#### 4. 实时状态刷新 (Real-time Polling) ✅
**机制**:
- ✅ 对于"处理中"的任务，启用轮询 (Polling)，每 **5 秒**自动更新一次状态
- ✅ 静默刷新：不显示 loading，用户体验更流畅
- ✅ Toast 通知：任务完成后通知用户"任务 xxx 已完成"

**代码实现**:
```typescript
useEffect(() => {
  if (hasProcessingTasks) {
    pollingRef.current = setInterval(() => {
      loadTasks(false); // 静默刷新
    }, 5000);
  }
}, [tasks]);
```
