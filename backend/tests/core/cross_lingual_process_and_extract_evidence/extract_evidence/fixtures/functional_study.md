# Functional Study: ABCA3 Variant Pathogenicity Assessment

## Assay System

Functional characterization was performed using HEK293 cells expressing wild-type and mutant ABCA3. The assay system measured phospholipid transport activity in reconstituted vesicles.

## Tested Variants

Three variants were tested: p.Glu628Lys (novel), p.Leu101Pro (known pathogenic), and p.Val1399Met (benign control). Each variant was transiently expressed and compared to wild-type ABCA3.

## Controls

Positive controls included wild-type ABCA3 (normal function) and p.Leu101Pro (known loss-of-function). Negative controls included empty vector transfection. The assay was performed in triplicate with three independent biological replicates.

## Quantitative Results

p.Glu628Lys showed 15% residual phospholipid transport activity compared to wild-type (p<0.001). p.Leu101Pro showed 8% residual activity. p.Val1399Met showed 95% activity (comparable to wild-type).

## Functional Interpretation

The p.Glu628Lys variant demonstrated significantly reduced phospholipid transport, consistent with loss-of-function. The functional result supports pathogenic classification (PS3 evidence). Disease mechanism is loss-of-function through impaired surfactant metabolism.

## Statistical Analysis

Differences were assessed using one-way ANOVA with Tukey's post-hoc test. All experiments were performed in triplicate. The OddsPath was calculated as 45.2, supporting PS3_very_strong evidence.
