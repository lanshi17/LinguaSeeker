# Components (Legacy)

> Reserved directory structure. All subdirectories contain only `.gitkeep` placeholders.

Active component implementations live in:

| Directory | Purpose |
|-----------|---------|
| `src/components/ui/` | Shared UI primitives (Button, Card, Input, etc.) |
| `src/components/layout/` | Page layout components (DashboardLayout, Sidebar) |
| `src/features/*/components/` | Feature-scoped components |

This directory is kept for potential future shared component extraction.
